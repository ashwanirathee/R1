# Experiments

This section is a tutorial-style area for R1 experiments. Use it for research
logs, repeatable workflows, model comparisons, and lessons learned while testing
new robot capabilities.

## How To Use This Section

Each experiment page should explain:

- the goal of the test
- the setup and commands used
- the result
- what changed because of the result

## Current Experiment Areas

- Vision classification in `src/tasks/task_1`
- OpenCLIP zero-shot classification
- Threshold and margin analysis
- LLM-assisted classifiers
- Human label analysis

Start with [Vision Classification](./vision-classification).
