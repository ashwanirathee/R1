# Vision Classification

This tutorial tracks the vision classification experiments in
`src/tasks/task_1`.

## Goal

Compare different ways to classify visual inputs for R1 and understand which
approaches are reliable enough to use in the robot loop.

## Files

- `open_clip_zero_shot.py`
- `open_clip_threshold.py`
- `open_clip_logistic_regression.py`
- `open_clip_analysis.py`
- `llm_classifier.py`
- `llm_cloud_classifier.py`
- `human_label_analysis.py`
- `margin_visualization.py`

## Workflow

1. Prepare or inspect the dataset.
2. Run a baseline classifier.
3. Compare model confidence, margins, and failure cases.
4. Check results against human labels.
5. Record what should change in the next experiment.
