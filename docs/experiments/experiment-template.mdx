# Experiment Template

Copy this structure when adding a new experiment page.

## Goal

What are you trying to prove, disprove, or learn?

## Setup

List the dataset, commands, model, hardware, prompts, thresholds, and important
assumptions.

```bash
# command used for the experiment
```

## Result

Record the most important numbers, observations, screenshots, logs, or failure
cases.

## Takeaway

What changed because of this result?

## Next Step

What should be tested next?
